## Проверки и границы

GARAGE_VALIDATION.json доказывает сохранность прочих свойств и pivot, непересечение фрагментов одного исходного блока, равенство вырезанного объёма оконным тоннелям и отсутствие непрозрачной подложки в них. Боковые окна проверены с исключением разрешённых оконных рам/стоек.

non-garage-fixed/VALIDATION.json проверяет разрешённый diff всех Item и12бинарных roundtrip; ZERO_THRESHOLD_REVIEW.json проверяет любое положительное перекрытие окон отделкой, без порога площади. Итоговый аудит заменяет раннюю проверку3% и не скрывает мелкие декоративные перекрытия. Все49удалённых частей перечислены в ALLOWED_DELETIONS.json.

Новых геометрических пересечений не добавлено: изменённые гаражные детали — подмножества прежних, в остальных оболочках геометрия только удалялась. Старые внутренние декоративные стыки не перестраивались; полное отсутствие всех старых пересечений не заявляется. Runtime в Studio здесь не проверен.
