# V30 — оборудование и шесть этапов консоли

Три модели: Equip_ChipLab (28 деталей,6×4.25×4), Equip_DesignStation (28,6×4.2×4), Equip_TestBench (41,6×4.09×4). И шесть прозрачных иконок128×128 для cpu/case/sound/prototype/testing/launch.
