11 PNG: gotw_icon.png и rebirth_star.png256×256; rperk_speed/costs/start/hits/offline.png и mentor_icon.png128×128; title_frame.png / title_frame_rare.png / title_frame_legendary.png512×96. Все имеют настоящую прозрачность с сохранённой исходной альфой.

Иконки выполнены встроенным OpenAI ImageGen отдельным запросом на файл. gotw_icon основан на фактическом рендере Trophy_GOTW; остальные — оригинальные простые символы из ТЗ. Рамки титулов: обычная серебристая, редкая синяя, легендарная золотая, пустой тёмный однотонный центр без рисунков и текста. Отдельными правками убраны градиенты внутренней области; у растровой генерации возможны небольшие вариации RGB, статистика центра сохранена в VALIDATION.json.

PROMPTS.json содержит точные запросы, исходники и цепочки правок. Финальные изображения сохранены в V28/. Иконки уменьшены с сохранением пропорций и альфы; рамки обрезаны по видимой альфе и вписаны в512×96 без растяжения.
