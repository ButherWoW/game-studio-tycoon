# V28 — кубок игры недели, пьедесталы и билборд

Оригинальные модели из native Roblox Parts, без надписей, скриптов, mesh/texture/Decal или чужих брендов. ВсеAnchored, CanCollide/CanTouch/CanQuery=false, pivotцентр основанияY0, лицеваясторона+Z. Свечение толькоNeon, источниковсвета нет.

Trophy_GOTW — золотая статуэтка своего аркадного джойстика с двумя кнопками на синей площадке и золотой стойке. Пьедесталы1/2/3 — золото/серебро/бронза, гладкая верхняяплощадка4×4 оставляет центральные3×3 свободными под фигуру. Нативная Part `Plate` спереди предназначена длятекста игры. Billboard имеет двеопоры, native Part `Screen` ибирюзовуюNeonрамку. Screen смотрит+Z, тоесть граньBack у обычнойRobloxPart; игровомуSurfaceGui нужно использоватьBack.

Сделано собственнымPython-генератором, RBXMX экспорт иRBXM черезRojo. Рендерыфактическойгеометрии вpreviews/, исходники вsource/. VALIDATION.json иINDEPENDENT_VALIDATION.json: независимыйразбор фактическогоXML,15-осевойOBB/SAT; касания разрешены, положительныхобъёмных пересечений нет. Проверены размеры/лимиты/pivot, свободные верхниеплощадки, классы/закрепление/именаScreen иPlate. Визуально проверены все5моделей и фронтальныйвидScreen.
