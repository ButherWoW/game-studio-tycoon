# V29 — все ассеты стройки

`construction-pack` содержит четыре шаблона: Construction_Scaffold (12 деталей), Construction_Fence (4), Construction_Crane (52), Construction_Sign (7).

`builder-pack` содержит нативного R15 BuilderNPC (19 деталей, 15 Motor6D), отдельную каску BuilderHat (3 детали), одежду builder_shirt/pants 585×559, исходники и превью фактических текстур и геометрии. Внутренних пересечений моделей нет; подробные отчёты лежат в каждой папке.

## Установка

Dev1: импортировать один формат каждого шаблона в ServerStorage.Upgrades. Перед установкой BuilderNPC назначить загруженные ShirtTemplate/PantsTemplate ID: в файле стоят нули. Сохранить pivot на HumanoidRootPart (Y=3) и HipHeight=2. Для персонажа используется корневой pivot, для секций — центр основания на Y=0. Стандартные суставы поддерживают ConstructionController. Молоток и доску добавляет игра; каска — отдельный Accessory с HatAttachment.

Dev2: перед подключением моделей исправить задние углы расстановки ConstructionService. Инструкция, воспроизводимые расчёты и предлагаемый патч находятся в construction-pack. В src этой пачкой ничего не меняется. После предложенной поправки проверены все 42 секции лесов и 21 секция забора: пересечений нет, бюджет сохраняется.
