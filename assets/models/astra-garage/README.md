# Гараж Game Studio Tycoon — готовый набор Roblox

Оригинальные 3D-объекты по нашим концептам: тёплое дерево, синие кресла, толстые мониторы, золотой свет и яркие картриджи. Расстановка разработана заново по просьбе владельца. Все модели редактируются обычными инструментами Roblox Studio.

## Быстро посмотреть

1. Распакуй ZIP.
2. В Roblox Studio открой **Garage_Showcase.rbxl** через **File → Open from File**.
3. Внутри уже собран гараж с четырьмя рабочими местами, зоной отдыха, кофе, полкой хитов, растениями и светом. Крыша снята для обзора; передняя сторона открыта для входа.
4. Для импорта в существующую карту: в Explorer выбери Workspace → **Insert from File** → **Garage_Assembled.rbxm**.
5. Отдельные предметы лежат в папке **models/** в формате **.rbxm**. Файлы **.rbxmx** — текстовые версии тех же моделей, импортировать обе версии не нужно.

**Garage_Roof_Optional.rbxm** — отдельная крыша для собранного гаража. При установке совмести её pivot с pivot гаража. Крыша в models/GarageRoof.rbxm предназначена для большой 60×60 оболочки, а не компактной сцены.

## Размеры и установка в игру

- Собранная авторская сцена занимает **45×45 studs** внутри стандартного участка 60×60. Предметы расставлены для красивой композиции, а не по старым координатам Config.
- Отдельная модель GarageWalls остаётся **60×60** для текущей схемы игры. Высота боковых стен 13, конёк 18 studs.
- Стол: ширина 7.6, глубина 3.5, верх столешницы Y=3. Кресло: сиденье около Y=1.9; монитор устанавливается основанием на столешницу.
- Pivot мебели — (0,0,0) у основания. У лампы pivot на потолочном креплении, у вывески — центр панели. У крыши pivot совпадает с pivot оболочки.
- Столы, компьютеры, тумба и постеры смотрят лицом к +Z. Кресло содержит PcSeat, ориентированный к +Z модели; текущий поворот Chair=180° в Config разворачивает его к столу.
- **Upgrades_Import.rbxm** содержит 9 шаблонов с именами текущего проекта: Desk1, PC1, GarageWalls, Chair, Desk2, Coffee, Posters, PCPro, HitShelf. После импорта перенеси сами шаблоны в существующую **ServerStorage.Upgrades**, сохранив имена. Не создавай вложенную Upgrades внутри Upgrades и не оставляй две модели с одинаковым именем.
- Импорт шаблонов сохраняет старую раскладку Config. Чтобы в игре была именно авторская расстановка всей сцены, разработчику надо отдельно согласовать координаты и покупки. Исходный код игры этим комплектом не изменяется.
- Ворота, ящики и кофемашина — статические объекты; сценарии анимации/взаимодействия не включены. Надписи на вывеске не зашиты: название студии может выводить код игры.

## Правки Dev 2 перед подключением

- **Свет:** в лампе на столе было 23 источника света с тенями (по одному на каждую деталь скругления). Теперь один источник без теней. Тени оставлены только у четырёх больших потолочных ламп гаража.
- **Полка хитов** подогнана под места картриджей в коде (`ModelFactory.hitShelfSlot`): ширина 11.2, доски на высоте 0.3 / 2.6 / 4.9, 2 ряда по 5 мест. Декоративные картриджи сняты: настоящие хиты ставит игра.
- **Ворота в задней стене** раздвинуты к краям (X ±17.6, ширина 14): центр стены свободен под Posters (Config: X 0, Z −28.8).
- Превью в previews/ остались от первой версии: на них ворота стоят в середине стены, а полка шире.

## Проверка

Все 20 файлов моделей прочитаны и собраны через Rojo 7.4.4 в бинарный RBXM, демонстрационная сцена — в RBXL. Проверены положительные размеры, повороты, PrimaryPart, Anchored и PcSeat. Нет Script/LocalScript/ModuleScript и внешних текстур/мешей. Проверка: VALIDATION.json.

**В Roblox Studio сцена ещё не открывалась:** здесь Studio не установлен. Посадку R15, визуальные материалы, свет и производительность требуется окончательно проверить в Studio. Детальная сцена содержит около 4 тысяч видимых деталей и подготовлена с приоритетом качества, выбранным владельцем; скорость на телефоне не замерена.

Превью в previews/ отрисованы из той же геометрии, что экспортирована в модели. Это не новые AI-концепты и не скриншоты Studio; материалы и локальное свечение в самом движке будут отличаться.

## Палитра и исходники

Дерево #A0703C / #C18B50, синие акценты #3D7BFF / #285AC4, золото #FFC93C, тёплый свет #FFD9A0, бетон #8C8C8C. Скругления — из нативных блоков, цилиндров и сфер. Коммерческое использование объектов в вашем проекте не требует сторонних моделей или покупки текстур. Заимствованных моделей и логотипов нет.

Геометрия воспроизводится из source/build_kit.py. Для пересборки превью нужны Pillow и NumPy; для бинарного экспорта — Rojo. Назначение pivot проверено по [Roblox Pivot tools](https://create.roblox.com/docs/studio/pivot-tools), посадочные места — по [Roblox Seat](https://create.roblox.com/docs/reference/engine/classes/Seat), материалы — по [Roblox Material](https://create.roblox.com/docs/reference/engine/enums/Material).
