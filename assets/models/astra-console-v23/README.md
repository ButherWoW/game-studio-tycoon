# V23 — своя консоль и платформы

Три стадии собственной консоли для третьего этажа: чертёж, открытый прототип и готовое устройство на витрине. Оригинальная форма из двух синих секций с золотыми крышками и низкой бирюзовой перемычкой; отдельный ступенчатый геймпад. Между стадиями сохраняется узнаваемый дизайн.

| Шаблон | Детали / лимит | ГабаритыXYZ, studs | Свет |
| --- | --- | --- | --- |
| Console_Design |39 /60|5.6×2.78×5.2|0|
| Console_Prototype |46 /80|5.6×3.64×5.2|0|
| Console_Launch |34 /100|5.6×3.67×5.2|1, без теней|

В `models/` каждый шаблон в RBXMX и RBXM: импортировать один формат, не оба. Pivot — центр основанияY0, лицевая сторона+Z; native Parts, без скриптов, внешних mesh/texture/Decal. Всё закреплено, декоративные детали без коллизий.

`icons/` содержит platform_pc.png, platform_phone.png, platform_console.png:128×128PNG с прозрачностью. Иконка консоли повторяет фактическую модель Launch. Точные запросы встроенного ImageGen и пути к исходникам в icons-pc-phone-prompts.json и icons-console-prompts.json. Исходная прозрачность сохранена при уменьшении.

## Проверки и превью

Модели построены собственным Python-генератором из примитивов Roblox; преобразование RBXMX→RBXM через Rojo. Исходники и воспроизводимые проверки в `source/`. MODELS_VALIDATION.json — проверка сборки; INDEPENDENT_VALIDATION.json — отдельный разбор фактического XML и15-осевой SAT: положительных объёмных пересечений нет, касания разрешены. Габариты, pivot, лимиты, классы, свойства света и отсутствие скриптов проверены.

`previews/Console_ContactSheet.png` показывает настоящую геометрию всех стадий, общие и фронтальные виды. `Console_Product_Closeup.png` — устройство крупно; `Platform_Icons_ContactSheet.png` — прозрачные иконки на двух фонах и при40px. Рендеры выполнены из той же геометрии, это не Studio-скриншоты. Свечение Neon и PointLight окончательно проверяются в Roblox.

## Подключение

Подробности в INTEGRATION.md. Dev1 импортирует шаблоны и загружает иконки, Dev2 подключает смену стадий и выбирает окончательное место. В сцене одновременно одна стадия. ЭтажY28 учитывает код игры. Зону лифтаX−23…−17,Z21…27 не занимать.

Прототип содержит статичный Neon-диод PrototypeIndicator. Его мигание подключает код игры: модель не содержит скриптов. Сама пачка не меняет цены, прогресс, доход, Config или Image ID. Загрузка в Roblox и runtime-тест не выполнялись; проверка в Studio перечислена в INTEGRATION.md.
