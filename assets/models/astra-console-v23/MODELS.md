# V23 — собственная консоль: три стадии

Оригинальная консоль из нативных Roblox Parts: два синих боковых модуля, золотые верхние крышки, циановая перемычка, маленький золотой ромб. Контроллер имеет ступенчатый прямоугольный силуэт, светлую крестовину из четырёх раздельных кнопок, циановую центральную панель и две золотые кнопки. В дизайне нет чужих брендов, реальных консолей, текстур, мешей или надписей.

| Шаблон | Parts / лимит | Ширина × высота × глубина | Свет |
| --- | --- | --- | --- |
| Console_Design |39 /60|5.6×2.78×5.2|нет|
| Console_Prototype |46 /80|5.6×3.64×5.2|нет|
| Console_Launch |34 /100|5.6×3.67×5.2|1 PointLight, Shadows=false|

Все детали Anchored, CanCollide=false, CanTouch=false, CanQuery=false. Основание на Y=0, pivot — центр основания (0,0,0), передняя сторона +Z. Все габариты меньше 6×5×6. Каждый шаблон заменяет предыдущий, не накладывается сверху на него.

## Стадии

Design: деревянный чертёжный стол на четырёх ножках; синяя бумага с геометрическим чертежом двух модулей и контроллера; три карандаша с отдельными тёмными концами/светлыми ластиками, три цветовых образца.

Prototype: открытые боковые корпуса, видимые зелёные платы, чипы, конденсаторы и цветные прямоугольные трассы проводов. Снятые золотые крышки стоят на задней стойке. Контроллер — перед консолью. `PrototypeIndicator` — отдельная циановая Neon-деталь без PointLight. Индикатор статичен в ассете: требуемое мигание реализует код игры после установки, без скриптов внутри модели. Для этого можно менять Transparency/Color именно этой детали.

Launch: закрытые синие модули с золотыми крышками, циановыми световыми полосами и тёмными вентиляционными полосами. Стоит на устойчивом постаменте с золотым поясом и циановым краем. Единственный PointLight внутри переднего Display_CyanEdge: Range=8, Brightness=0.55, Shadows=false. Контроллер лежит перед устройством.

## Проверка и происхождение

Создано программно как собственная геометрия; экспорт Roblox XML и бинарного RBXM через Rojo. Не используется ImageGen для 3D-моделей. Превью — рендер действительных деталей из source/build_console.py, а не нарисованная концепция; Neon и освещение Roblox окончательно проверять в Studio.

Сохранены исходники построения, XML-экспорта и рендера. Python3 + Pillow + NumPy; Rojo требуется только для бинарного RBXM. Для воспроизведения из каталога пакета:

    python3 source/build_console.py
    python3 source/validate_models.py

MODELS_VALIDATION.json содержит габариты/лимиты/классы/свет. Собственная проверка SAT по 15 осям проверила 2337 пар деталей: положительных объёмных пересечений нет, касание поверхностей разрешено. Отдельный независимый аудит читает уже экспортированные RBXMX; его результаты в INDEPENDENT_VALIDATION.json. Визуально проверены все три вида, геймпад и крупный вид готового продукта. Для внутренностей прототипа приложен Console_Prototype_Top.png.

В Roblox Studio здесь не выполнялись импорт, проверка на фактическом 3-м этаже или runtime-мигание. Итоговую координату размещения задаёт команда по актуальным Upgrades/Console, сохраняя зону лифта и проходы.
