# V16 Mascots — Batch 2

Four native Part models in models/, four 256px transparent shop icons alongside this file, rendered geometry previews in previews/. Models_ContactSheet.png shows actual model geometry; Icons_ContactSheet.png shows the illustrated shop icons. The combined ContactSheet.png compares each model with its icon.

Models have a Body PrimaryPart, base-centered pivot at Y=0 and face +Z. All parts are anchored, noncolliding; move the whole model with PivotTo to retain its assembled shape. There are no scripts, meshes, textures or lights. Neon is reserved for rare and higher tiers. VALIDATION.json records part counts and height. Icons are stylized illustrations of the same theme and palette, rather than exact geometry renders.

Upload icons as Roblox Images and import the .rbxmx files into the mascot storage selected by the game developer. Motion, bonus logic and ownership are integrated by Dev 1/Dev 2. Exact built-in ImageGen prompts and source paths: prompts.json.
