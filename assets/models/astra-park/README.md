# Astra V7 — парк вокруг спавна

Готовая модель **Park**: круглый газон диаметром 140 studs, открытая центральная площадка 16×16, извилистые дорожки, прогулочное кольцо, 31 дерево трёх видов, 10 кустов, 5 клумб, 8 фонарей, 5 урн, пруд с кувшинками и мостиком. Лиственные деревья, берёзы и ступенчатые ели отличаются формой и оттенками. Высота установленных деревьев 10–25 studs, фактические значения — в layout.json.

**577 обычных деталей Roblox**, включая все части геометрии, без дополнительных невидимых Pivot-деталей. PrimaryPart — существующая деталь модели, PivotOffset проверен расчётом. Модель редактируется в Studio, скриптов и внешних MeshId/TextureId нет.

Палитра: газон #6BBF59, дорожки #D9C9A3, дерево #9C6B3F; несколько зелёных оттенков для крон, мягкий голубой пруд, пастельные цветы. По одному PointLight без теней на каждый фонарь.

## Открыть

1. **Park_Showcase.rbxl** — открыть в Roblox Studio через File → Open from File. Это плейс для осмотра ландшафта, без игрового кода тайкуна.
2. **models/Park.rbxm** — импортировать весь парк в существующий плейс.
3. Остальные **models/*.rbxm** — самостоятельные деревья, куст, клумба, фонарь, урна и пруд с мостиком для правок композиции.
4. **LandscapeObstacles.rbxm** — отдельный Folder регистрации препятствий для артефактов, не видимый декор.

XML .rbxmx — альтернативные исходники; одновременно с бинарными версиями импортировать их не нужно. Полный список размеров:

## Для Dev 2 — подключение к игре

### Ландшафт и текущий StartPark

**Park надо размещать отдельной моделью в Workspace, рядом со StartPark, а не одной огромной Model внутри StartPark.** Причина: StartParkService.collectObstacles считает габарит каждой модели препятствием; весь парк одним препятствием закроет область поиска картриджей.

Текущие игровые скамейки Bench1..6 (радиус 28, углы 30°+60°×i), JobBoard (0,12) и Pawnshop (0,−12) оставлены кодом игры: новый ландшафт не дублирует их, а резервирует места. Пустой центр 16×16 сохранён. Парк не содержит ноутбуков, доски заданий, ломбарда или фиксированных мест появления артефактов — это отдельные игровые объекты.

**LandscapeObstacles.rbxm** содержит Folder `LandscapeObstacles` с индивидуальными невидимыми BasePart-прокси для деревьев, кустов, клумб, пруда, фонарей и урн. Они закреплены, невидимы, без коллизий, касаний и участия в лучах. Их размеры дают консервативный радиус каждого препятствия, который уже умеет читать collectObstacles.

- Добавить этот Folder в **workspace.StartPark до запуска collectObstacles**. Не регистрировать траву, дорожки и площадку спавна как препятствия.
- Не создавать пустой StartPark заранее только ради реестра: WorldService.ensureStartPark тогда пропустит создание ноутбуков, доски, ломбарда и CartridgeSpots. Подключение делается после создания игровых объектов, но перед сбором препятствий в StartParkService.
- При смещённом спавне парк и все позиции прокси надо сдвинуть на одинаковый XZ-offset. У Folder нет Model:PivotTo; сместить его части отдельно или создать реестр из layout.json относительно спавна.
- Пока реестр не подключён, нельзя считать случайные точки артефактов проверенными в игре: один луч вниз сам по себе не заменяет исключение пруда и деревьев.

### Дорожки и кольцо участков

12 выходов к участкам идут с шагом 30° и заканчиваются на радиусе 69.25. Углы/точки есть в layout.json. Для шести участков используются соответствующие выходы через один; для иных раскладок внешние соединения надо строить по фактическим входам участков.

WorldService сейчас рисует старые прямые PlotPaths начиная с радиуса 34. При подключении нового ландшафта **обрезать их внутри парка и продолжать от выходов к фактическим передним краям участков**, иначе старые полосы будут видны на газонах рядом с извилистыми дорожками. Цвет продолжений согласовать с #D9C9A3.

Проект рассчитан на текущую нормальную раскладку **12 участков**. При 6–7 участках WorldService сейчас задаёт радиус кольца 90, а ближняя кромка участка оказывается на радиусе 60: парк диаметром 140 туда не помещается в плане. Для этих серверов нужно увеличить минимальный радиус кольца хотя бы до **102 studs** либо адаптировать ландшафт. Это задача подключения: исходный WorldService этим комплектом не изменён. При 12 участках ближняя кромка дальше 122, пересечений с парком нет.

## Проверка артефактов

Фиксированные CartridgeSpots в парк не добавлялись. Расчёт использовал актуальные параметры: радиус 10..52, отступ от препятствий 5, дистанция между картриджами 14, до 40 попыток на одну точку.

- 20 000 проб равномерно по площади: 31.245% свободных точек на всех поверхностях, 12.4% свободных точек именно на газонах, вне дорожек.
- Свободные газонные точки присутствуют в диапазонах радиусов 10..24, 24..38 и 38..52; карта — previews/ArtifactCoverage_QA.png.
- В 200 симуляциях алгоритм нашёл все шесть точек в 200 случаях.

Это **офлайн-расчёт по консервативным габаритам**, не игровой raycast и не гарантия после произвольной перестановки объектов. Текущий игровой код может выбрать и дорожку; если нужны артефакты строго на траве, Dev 2 должен добавить соответствующий фильтр поверхности. Превью — проекции фактической геометрии, не скриншоты Studio.

## Исходники

source/build_park.py — оригинальная геометрия и воспроизводимая композиция; source/validate_export.py — проверки и сборка; source/render_geometry.py — превью. Зависимости: Pillow/NumPy для изображений, Rojo для RBXM. Весь набор сделан из собственных обычных деталей Roblox и может использоваться в вашем коммерческом проекте без покупки сторонних моделей и текстур.
