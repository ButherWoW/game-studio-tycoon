# Build Your Game Studio Tycoon (Roblox)

Тайкун в духе **Game Dev Tycoon** для Roblox: открываешь игровую студию в гараже, разрабатываешь и выпускаешь игры, получаешь оценки критиков и деньги, нанимаешь команду и вырастаешь в мировую корпорацию.

> Статус: **подготовка к запуску** — фазы 0–7 в `main`, идут тесты в Studio, создание товаров и публикация. План — [docs/ROADMAP.md](docs/ROADMAP.md). Запуск — [docs/LAUNCH.md](docs/LAUNCH.md), страница игры — [docs/STORE_DESCRIPTION.md](docs/STORE_DESCRIPTION.md), что нового — [docs/PATCH_NOTES.md](docs/PATCH_NOTES.md).

## Core loop

1. Выбрать жанр и тему → распределить фокус (геймплей / графика / звук / сюжет)
2. Студия разрабатывает игру — сотрудники за столами дают очки
3. Релиз → оценка 1–10 → доход
4. Апгрейды офиса, сотрудники, исследования → игры лучше и дороже
5. Rebirth: «звёзды студии» для постоянных перков

## Что есть в игре

- **Студия:** старт в парке (ноутбук, подработки) → гараж → офис → 2-й и 3-й этаж; отделка (Сакура, Северное сияние, Чёрное золото) и 4 стиля мебели; декор, постеры, вывеска студии.
- **Игры:** 10 жанров и 17 тем (открываются по прогрессу), фокус по 4 направлениям, события разработки, критики 1–10, мини-аркада после релиза, франшизы, контракты издателей.
- **Команда:** найм, навыки, перки, наставничество, своя внешность и скины сотрудников, легендарные сотрудники, настроение.
- **Хиты:** полка картриджей с пассивным доходом, «Обновление / DLC», воры и погоня.
- **Каждый день и неделю:** события дня (hh:30 UTC), Золотой час (19:00 UTC), ночь хакатона, выставка раз в час, гейм-джем, «Игра недели», Зал славы, сезонный пропуск, задания, награды за вход, праздники.
- **Социальное:** экскурсии и лайки, рейтинги, холдинги, совместная разработка, обмен косметикой, подарки, приглашения друзей, награда за группу, рекламные щиты у спавна.
- **Поздняя игра:** конкуренты, своя консоль, стример, налоги, IPO, биржа, дивиденды, банк и кредиты.
- **Статус:** дерево перков Rebirth, титулы над головой, достижения, 12 маскотов, VIP, бонус Roblox Premium, бонус возвращения, сейф в парке.
- **Монетизация без лутбоксов:** рекламные кампании, геймпассы, продукты, отделка, маскоты, сезонный пропуск.
- **30 языков.**

## Быстрый старт

1. Установите [Roblox Studio](https://create.roblox.com/) и [Rokit](https://github.com/rojo-rbx/rokit).
2. Склонируйте репозиторий и установите инструменты:
   ```bash
   git clone <url этого репозитория>
   cd game-studio-tycoon
   rokit install
   ```
3. Запустите синхронизацию: `rojo serve`
4. В Studio установите плагин Rojo, нажмите **Connect** — код появится в плейсе.
5. Для теста в плейсе нужны: `Workspace.Plots` (части Plot1, Plot2…) и `ServerStorage.Upgrades` (модели Desk1, PC1, …). Для сохранений включите *Game Settings → Security → Enable Studio Access to API Services*.

## Структура

```
src/
  server/            ServerScriptService — вся логика денег и оценок
    Services/        DataService, DevelopmentService, MonetizationService и ещё ~70 сервисов
  client/            StarterPlayerScripts — UI
  shared/            ReplicatedStorage — конфиги и формулы
    Config/          весь баланс: Genres, Topics, Upgrades, AdCampaigns, DailyEvents, …
```

**Правило №1:** деньги, очки и оценки считает только сервер. Клиент только показывает и просит.
