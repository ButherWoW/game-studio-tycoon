# Уведомления, приглашения, обмен (волна 2)

Код: `Config/Friends.luau`, `FriendRemotes.luau`; сервер — `NotifyService`, `ReferralService`,
`TradeService`; клиент — `NotifyPrompt`, `FriendsController`, `TradeWindow`. Кнопки «📨 Пригласить
друга» и «🔁 Обмен» — в шапке окна «🏘 Студии» (TourWindow, слот меню 15).

## 1. Уведомления Roblox (Experience Notifications)

### Что сделано в игре
- `NotifyService` один раз предлагает включить уведомления после важного момента: гараж куплен
  в этой сессии или (гараж уже был) вышла игра в этой сессии; не раньше чем через 60 с после входа.
- Клиент (`NotifyPrompt`) ждёт, пока закроются окна игры, вызывает
  `ExperienceNotificationService:CanPromptOptInAsync()` и, если можно, `PromptOptIn()` —
  это системное окно Roblox.
- В профиле `notify = { prompted, at, tries }`: показали — больше не предлагаем; Roblox не дал
  (Studio, возраст, выключено) — пробуем в следующих сессиях, всего 3 раза.
- Аналитика: событие `NotifyPrompt` (поле `shown` / `unavailable`).
- В Studio `CanPromptOptInAsync` обычно возвращает false — окно видно только в опубликованной игре.

### Что сделать Dev 1 в Creator Hub
1. Creator Hub → игра → **Engagement → Notifications** → **Create a notification string**.
2. Предлагаемые строки (на английском; Roblox сам переводит, можно добавить переводы вручную):
   - `studio_income` — «Your studio earned {amount} while you were away. Come collect it!»
   - `friend_joined` — «{friendName} is building a game studio. Join them!» (для приглашений)
   - `season_ending` — «The season ends soon — claim your rewards!»
   Параметры в фигурных скобках задаются при отправке.
3. Скопировать **ID строки** (asset id) каждой строки — он нужен внешнему сервису.
4. Включить уведомления в настройках игры, если выключены.

### Отправка (вне игры, не в этом репозитории)
Из игрового сервера уведомление отправить нельзя. Отправляет внешний сервис (cron/воркер)
через **Open Cloud User Notifications API**:
- API-ключ в Creator Hub → Open Cloud → API Keys, право `user.user-notification:write` для этой игры.
- `POST https://apis.roblox.com/cloud/v2/users/{userId}/notifications`
  ```json
  {
    "source": { "universe": "universes/<UNIVERSE_ID>" },
    "payload": {
      "message_id": "<ID строки из Creator Hub>",
      "type": "MOMENT",
      "parameters": { "amount": { "string_value": "$12 000" } },
      "join_experience": { "launch_data": "notify:studio_income" }
    },
    "analytics_data": { "category": "studio_income" }
  }
  ```
- Roblox сам доставляет только тем, кто включил уведомления, и сам ограничивает частоту.
- Кому и когда слать (офлайн-доход накопился, сезон кончается) — решает внешний сервис;
  данные можно брать из DataStore через Open Cloud DataStore API. Это отдельная задача.
- `launch_data` из уведомления приходит в `player:GetJoinData().LaunchData` — сейчас игра его
  не разбирает (кроме `ref:<userId>` для приглашений).

## 2. «Пока тебя не было»
Окно офлайн-дохода уже было; добавлено: сколько игрока не было («Тебя не было: 3 ч 20 мин»)
и пометка «копится не больше 4 ч», если ушёл дольше лимита (`Config/Offline.maxSeconds`).
Сервер кладёт время в атрибут `OfflineAway`.

## 3. Награда за приглашение
- Кнопка «📨 Пригласить друга» → `SocialService:PromptGameInvite` с `LaunchData = "ref:<userId>"`.
  Сколько приглашений отправлено — счётчик `referral.invitesSent` в профиле.
- Кто пригласил (только при первом входе нового игрока):
  `GetJoinData().ReferredByPlayerId` (приглашение или «Присоединиться» к другу) →
  `LaunchData "ref:<id>"` → друг Roblox, который уже на сервере.
- «Новый»: первый вход не раньше 10 мин назад, ни одной игры, без Rebirth. Проверяется один раз
  за жизнь профиля (`referral.checked`).
- Награды, когда новичок наиграл 5 минут (время копится и между сессиями):
  - новичку — **$2 000**;
  - пригласившему — **15 минут дохода + 10 минут кофе**, если он в этот момент на том же сервере
    (иначе ждём, пока окажутся вместе, до 7 дней). Не больше **10 наград в сутки (UTC)**;
    сверх лимита — тост «лимит исчерпан», награда за этого друга сгорает.
- Каждая сторона получает награду за конкретного новичка один раз.
- Аналитика: `Referral` (`joined_invite/launch/friend`, `new`, `inviter`, `inviter_capped`,
  `invite_sent`), деньги — источник `TimedReward / referral`.
- Числа — `Config/Friends.referral`.

## 4. Обмен
- Меняются: скины, постеры и маскоты **за $** (`Friends.tradeable`: не `premium`, маскот
  `how = "cash"`) и деньги. Купленное за Robux, маскоты за достижение и группу — нет.
  Предметы за $, полученные из стартового набора или сезона, тоже обмениваются (их можно купить за $).
- Ход: «🔁 Обмен» → выбрать игрока → у него плашка «Принять / Отказать» (30 с) → оба собирают
  предложение (до 6 предметов и деньги, не больше 50% своего баланса) → оба «✅ Подтвердить».
  Любое изменение снимает оба подтверждения и запирает кнопку на 3 с.
- Сервер перед обменом проверяет заново: оба на сервере, предметы у отдающих, у получателей таких
  нет, нет долга, деньги в пределах лимита. Потом забирает и выдаёт одним куском (без yield).
  Отданный скин снимается с сотрудников, постер — со стены, маскот — с плеча.
- Ограничения: игрок в долгу (cash < 0) не меняется (иначе уводил бы предметы от приставов);
  запрос не чаще раза в 3 с; после отказа тому же игроку — через 30 с; после обмена — пауза 10 с;
  обмен целиком не дольше 5 минут; один обмен на игрока.
- Аналитика: `Trade` (`started`, `done` — значение = число предметов, `cancelled`).
- Числа — `Config/Friends.trade`.

## Как проверить в Studio (2 игрока)
Test → Clients and Servers → 2 Players (студийные тестовые деньги — для обмена деньгами).
1. **Обмен.** У Player1 купить за $ пару скинов/постер/маскота. Player1: меню 🏘 → «🔁 Обмен» →
   Player2. У Player2 плашка → «Принять». Окно открылось у обоих. Player1 добавляет предметы и
   +$1K; у Player2 справа видно. Кнопка «Подтвердить» 3 с серая. Player2 добавляет деньги —
   подтверждение Player1 снимается. Оба подтверждают → предметы перешли (магазин скинов/постеров,
   маскот), деньги перешли, тосты «Обмен завершён».
2. Нельзя: премиум-скин в списке не появляется; предмет, который у партнёра уже есть, —
   тост «уже есть»; × у одного — «обмен отменён» у обоих; выход игрока — отмена.
3. **Приглашение.** «📨 Пригласить друга» в Studio обычно пишет «недоступно» — это нормально,
   проверять в опубликованной игре. Награду можно проверить так: новый профиль (другой
   тестовый аккаунт или очищенный ключ) входит, когда на сервере уже есть друг Roblox, →
   тост «Тебя позвал…», через 5 минут $2 000 новичку и 15 мин дохода + кофе другу.
4. **Уведомления.** Только в опубликованной игре: купить гараж, через минуту — системное окно
   Roblox «Включить уведомления». Больше не появляется.
5. **Офлайн.** Выйти больше чем на 5 минут (или поправить `lastLogout`) — в окне «Пока тебя не
   было» строка «Тебя не было: …».
