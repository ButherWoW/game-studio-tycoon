# Страница игры в Roblox: описание, ключевые слова, анкета

Название — **Build Your Game Studio Tycoon** (владелец, 05.11, #4); русская локализация названия — «Создай свою игровую студию».
Обновлено 05.11 (Dev 2, ветка `docs/launch-pack`): под текущий набор фич в `main` (события дня, сейф, Premium, дерево перков Rebirth, титулы, игра недели, щиты, стили, маскоты, биржа и т. д.).

Правила для всех текстов: **без брендов** (никаких названий реальных консолей, компаний и игр), без обещаний, которых нет в игре, без кодов сейфа. Описание — до 1000 символов (лимит Roblox; эмодзи могут считаться за 2 символа — тексты ниже ≈ 840–880). Обновлять после каждого крупного апдейта.

## 4. Шаблон списка обновлений (update log)

В описание игры — только 2–3 строки сверху («🆕 Обновление …»), полный список — в группе и Discord (`docs/PATCH_NOTES.md`). Каждый апдейт = новая строка сверху, старые через 2 обновления убирать.

**EN**
```
🆕 UPDATE <N> — <short name> (<date>)
⭐ NEW: <main feature in one line>
✨ <second feature>
🛠 Fixes and balance
🎁 Code in our group! (if there is one)
```

**RU**
```
🆕 ОБНОВЛЕНИЕ <N> — <название> (<дата>)
⭐ НОВОЕ: <главная фича одной строкой>
✨ <вторая фича>
🛠 Исправления и баланс
🎁 Код — в нашей группе! (если есть)
```

Название обновления в заголовке игры (по желанию владельца): `[UPDATE 2] Build Your Game Studio Tycoon` — менять только когда апдейт реально вышел.

## 5. Ключевые слова и идеи для поиска

Roblox ищет по названию и описанию — слова должны естественно стоять в тексте, без «простыней» тегов.

- **EN:** tycoon, game dev, game studio, simulator, build, office, make games, idle, business, empire, rebirth, mascots, pets, trading, stock market, co-op.
- **RU:** тайкун, симулятор, игровая студия, разработчик игр, создай игру, офис, бизнес, империя, ребёрс, питомцы.
- **Жанр в Creator Hub:** Simulation (Tycoon). Подходит и «Business»-сабжанр, если доступен.
- **Не использовать:** названия реальных игр, консолей и компаний, слова «free robux», «admin».

## 6. Анкета Experience Guidelines / Maturity — черновик ответов

Заполняет владелец (Creator Hub → Experience → Audience/Maturity & Compliance). Ответы ниже — по реальному содержимому `main` на 05.11. Ожидаемый результат: **Minimal / Mild**, без ограничения 17+.

| Вопрос (смысл) | Ответ | Почему (что в игре) |
| --- | --- | --- |
| Violence (насилие, оружие) | **None** | Нет боёв, оружия и урона. «Кража» картриджа — догонялки: дотронулся до вора — картридж вернулся. |
| Blood / gore | **None** | Нет крови и ранений. |
| Fear / horror | **None или Mild** (рекомендую Mild, если анкета спросит о «страшных темах») | Жанр «Хоррор» и темы «Призраки», «Тыквы» — это названия жанров для игр внутри игры (иконки, обложки). Призраки мультяшные и дружелюбные (маскот «облачко-привидение», сотрудник «Призрачный кодер» — полупрозрачный). Нет скримеров, тёмных сцен и пугающих звуков. |
| Crude humor | **None** | |
| Romance | **None** | |
| Alcohol, drugs, tobacco | **None** | Есть кофе и пицца. |
| Strong language | **None** | Ввод игроков (название студии, игры) идёт через фильтр Roblox (TextService) и свой фильтр мата. |
| Gambling (real money / Robux) | **None** | Ставок нет, платных случайных наград нет. |
| Paid random items / loot boxes | **No** | Все платные товары — с заранее известным содержимым (реклама, геймпассы, продукты, отделка, маскоты, сезонный пропуск). Сундуков нет. |
| Simulated gambling | **No** — но владельцу решить (см. примечание) | Биржа акций за игровые деньги (цена со случайным шумом), без Robux и без вывода. Это экономический симулятор, не казино. |
| Social: text/voice chat | **Text chat: yes** (стандартный чат Roblox). Voice — нет своего. | |
| Free-form user content | **Yes, filtered** | Игроки пишут названия студии и игр; показываются другим на вывесках, щитах и в рейтингах только после фильтра TextService. |
| Trading between players | **Yes** | Обмен косметикой, купленной за игровые $, и игровыми деньгами (до 50% баланса, дневной потолок). Купленное за Robux обменять нельзя. Обмен Robux/реальными деньгами отсутствует. |
| Paid items | **Yes** | Developer Products и геймпассы, без случайности. Roblox Premium — бонус +10% к доходу (официальная механика Premium). |
| Personal info / external links | **No** | Ссылок наружу в игре нет (Discord — только в соц. ссылках страницы). |
| Real-world brands | **No** | Все студии-конкуренты, консоли и издатели выдуманные. |

**Примечание для владельца:** если сомневаетесь в пункте про биржу — честнее отметить «simulated market without real value» в свободном поле. Перед отправкой анкеты пройтись по `docs/IDS.md`: все товары должны быть созданы в основной вселенной.
