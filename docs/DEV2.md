# Инструкция для Dev 2

Привет! Ты — **Dev 2**: работаешь в Roblox Studio — строишь карту и модели, тестируешь, публикуешь игру и принимаешь код.
**Dev 1 — Claude**: пишет весь код в `src/` и присылает Pull Request'ы.

Игра — тайкун игровой студии в духе Game Dev Tycoon: игрок в гараже делает игры (жанр + тема + фокус), получает оценки 1–10 и деньги, покупает апгрейды, нанимает сотрудников и дорастает до небоскрёба. Полный план — в [ROADMAP.md](ROADMAP.md).

---

## Шаг 1. Установка (один раз, ~30 минут)

1. Roblox Studio — https://create.roblox.com/ → войти в свой аккаунт Roblox.
2. GitHub Desktop — https://desktop.github.com/ → войти в GitHub.
3. Попросить владельца добавить тебя в репозиторий (Settings → Collaborators) и принять приглашение на почте.
4. GitHub Desktop → File → Clone repository → `erlbro-debug/game-studio-tycoon`.
5. VS Code — https://code.visualstudio.com/ + расширения **Luau Language Server** и **Rojo**.
6. Rokit — https://github.com/rojo-rbx/rokit (инструкция по установке там). Потом в папке проекта в терминале: `rokit install`.
7. В Studio: Plugins → Manage Plugins / Toolbox → найти и установить плагин **Rojo**.

## Шаг 2. Плейс (один раз)

1. Studio → New → **Baseplate**.
2. File → **Publish to Roblox** → новое место, название «Game Studio Tycoon (dev)».
3. View → **Collaborate** → включить Team Create, добавить владельца проекта.
4. Home → Game Settings → Security → включить **Enable Studio Access to API Services** (без этого не работают сохранения).

## Шаг 3. Подключить код и проверить прототип

1. В папке проекта: `rojo serve` (окно терминала не закрывать).
2. В Studio: вкладка Plugins → Rojo → **Connect**. В ServerScriptService появится `Server`, в ReplicatedStorage — `Shared`.
3. В **Workspace** создать папку `Plots`, в ней 6 Part с именами `Plot1` … `Plot6`: размер 60×1×60, Anchored = true, расставить по кругу вокруг спавна.
4. В **ServerStorage** создать папку `Upgrades` и в ней модели (Model) с точными именами:
   `Desk1`, `PC1`, `GarageWalls`, `Desk2`, `Coffee`, `Office`.
   Стройте их возле точки (0, 0, 0) — сдвиг от нуля станет позицией на участке. Для начала хватит простых блоков.
5. Нажать **Play**. Слева тестовые кнопки:
   - «Купить стол» → на твоём участке появляется Desk1;
   - «Сделать игру» → через 30 сек приходит оценка и деньги.
6. Остановить, снова Play — деньги и стол должны сохраниться.
7. Всё, что не работает → GitHub → **Issues → New issue → Баг** (что сделал, что увидел, скрин окна Output).

## Как мы работаем вдвоём

```
Ты (Dev 2): Issue «что нужно» ──► Dev 1: ветка + Pull Request
                                        │
Ты: GitHub Desktop → Fetch/Pull ◄───────┘
Ты: rojo serve → проверка в Studio → Merge PR (или комментарий «не работает, потому что…»)
```

**Правила:**
- Код (`src/`) — меняет Dev 1. Если хочешь поправить число (цену, время), можно прямо в `src/shared/Config` и коммит в GitHub Desktop.
- Модели и карта — только в плейсе (Team Create), в Git не кладём.
- Имена моделей и ID продуктов — единственное, что связывает плейс и код. Меняешь имя → пиши Dev 1.
- Перед началом работы всегда **Pull**, после — **Commit + Push**.
