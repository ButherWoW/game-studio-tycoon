## Источники и метод

Иллюстрации выполнены встроенным OpenAI ImageGen по отдельному запросу на каждый файл. Использованы собственные рендеры принятых моделей и визуальных ассетов из репозитория: V13 сотрудники, Office, Garage, V16 маскоты, V14 VIP и V15 стили. Это рекламные иллюстрации по игровым референсам, не скриншоты из Roblox Studio. Нативные Studio-скриншоты в этой сессии не предоставлялись. Игра показана как студия с деревянными столами, синими креслами, блочными персонажами и трёхэтажным HQ; без реальных брендов/консолей.

Точные промпты, ссылки на исходные рендеры, пути к генерациям и цепочки исправлений находятся в root-prompts.json, thumbnails-prompts.json и social-prompts.json. Финальные размеры получены пропорциональным масштабированием с минимальной центральной обрезкой, без растягивания изображения.

## Проверка и передача

VALIDATION.json содержит размеры, непрозрачность и SHA-256. V22_ContactSheet.png — общий лист; V22_Icons_100px_QA.png — иконки при100px, квадрат и круг для проверки обрезки. Превью/реклама проверяются на верный текст, число этажей, узнаваемые образы и свободные края.

Dev2: проверить и принять рекламные иллюстрации на соответствие фактическому состоянию игры. Dev1: после принятия загрузить нужные картинки в Creator Dashboard и оформить группу/сообщество по доступным настройкам платформ. Исходные PNG не содержат Roblox/Discord логотипов. Сохранить имена файлов и версии; предыдущие изображения не удаляются этим PR.
