# Проверка

Экспорт/повторный импорт glTF выполнен авторами сборок. См. validation.json в папках: Rock — 3248 треугольников каждый; Bush — 13476; Flowerbed — 12604, 7 узлов материалов; Pawnshop — 5888, 11 mesh-узлов. Проверены UV, отсутствие вырожденных треугольников и наличие текстур. Превью показывают реальную экспортированную геометрию, не концепт-картинки.

Нет скриптов или источников света в моделях. Внешние зависимости ограничены приложенными PNG/.bin; Roblox asset IDs ещё не получены. Текстуры — 2048; происхождение/приближённые карты описаны в README и MATERIAL_VALIDATION.json.

Roblox Studio недоступен: импорт SurfaceAppearance, масштаб, коллизии, доступность прилавка, текст вывески во всех локалях, производительность на телефоне и окончательный вид в освещении игры требуют проверки Dev 1. Не считать runtime-проверкой CPU-превью или успешную сборку Rojo.
