# V10 Achievement Medals

Three transparent 256×256 PNGs in `V10/`: bronze, silver, gold. Same master shape, blue ribbon and embossed star; silver and gold are color edits of the bronze master using built-in ImageGen. No text or numbers.

Exact prompts and original generated source paths: `prompts.json`. These optional medals still need Roblox upload and game integration by Dev 1/Dev 2. They do not include `menu_achievements.png`, supplied separately.
