Это статические обложки. Они не заменяют запись реальной игры, предусмотренную §3 LAUNCH. Монтажёр добавляет заголовки/субтитры в видеоредакторе и проверяет безопасные зоны конкретной площадки. Не показывать код сейфа при записи видео.

Стиль и герой V22 сохранены; маскоты, сейф, трофей и консоль сверены с принятыми моделями. Видеозапись, монтаж и публикация остаются за командой. Для обложек не нужны игровые Image ID или новые товары.

PROMPTS.json хранит точные промпты, референсы и цепочки правок. Встроенный ImageGen использован по одному изображению на сюжет; после него только resize/crop и QA. CONTACT_SHEET.png — обзор, не финальная обложка.
