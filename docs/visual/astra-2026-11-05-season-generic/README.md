# V18 — универсальный баннер сезона

`V18/season_banner_generic.png` — PNG1600×400, непрозрачный, надпись SEASON без номера. Основа — принятый season_banner.png из V18: тот же кубок, картриджи и студия, без привязки к конкретному сезону.

Сделано встроенным OpenAI ImageGen как целевая правка исходного баннера. Точный промпт, референс и путь к результату в PROMPT.json. Финальный размер нормализован до1600×400 с сохранением пропорций. Предыдущий баннер в репозитории сохранён.

VALIDATION.json содержит размеры, непрозрачность, SHA-256 и визуальную проверку текста. Preview.png показывает полный баннер и уменьшенный вид400×100.
