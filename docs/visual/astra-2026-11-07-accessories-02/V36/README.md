RBXM/RBXMX — два формата одной модели; импортировать только один. Сегментированные ленты имеют маленькие технологические зазоры; части жёстко связаны с Handle.

Dev1: после одобрения заменить наборы в ServerStorage.Skins.Skin_<id>. Корневой Model переименовать в Skin_<id>; Accessory остаётся его прямым ребёнком. Не наслаивать на старый набор. Каждый файл содержит один новый набор целиком, прежние дополнительные предметы (например, ручной картридж или секундомер) не включены. Одежда и ID скинов не меняются.

Каждый Accessory: Handle + HatAttachment, все части Anchored=false, Massless=true, без коллизии/касания/запросов, WeldConstraint к Handle. Лицо персонажа −Z, спина +Z. Правила статического декора Anchored/Y0 здесь не применяются. Нет скриптов, источников света, mesh/texture; фонарь декоративный и света не создаёт.

previews: три ракурса на модель и общий лист. Серая голова — ориентир офлайн-превью, в моделях её нет. Проверить реальные R15, Humanoid:AddAccessory, совместимость с причёсками, ходьбу/сидение и вид на телефоне в Studio. Реальную посадку не проверяли.

Проверки: 740 пар видимых деталей, пересечений нет с допуском 1e-6 stud. Невидимый Handle исключён из геометрии, но включён в бюджет и проверку сварок. Структура и 4 бинарных roundtrip PASS. source/build.py и validate.py воспроизводят сборку и проверки; нужны Pillow, NumPy и Rojo (его путь адаптировать).

Восемь обычных скинов теперь имеют предложенные обновления аксессуаров (#303 и эта пачка). Четыре премиальных, дополнительные варианты, ломбард и концепты этажей остаются в очереди.

Сообщение о коричневой рамке у NPC пока не привязано командой к конкретной модели/скину; эта пачка не заявляется как подтверждённое исправление того бага.
