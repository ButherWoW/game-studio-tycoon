## Происхождение и проверка

Встроенный OpenAI ImageGen: отдельный запрос на каждый sprite с transparent_background=true. Точные запросы, пути к генерациям и цепочки исправлений в PROMPTS.json. Исходная прозрачность сохранена при уменьшении до128×128; фон не вырезался по цвету. Без текста, брендов, логотипов, рамок и чёрной подложки.

VALIDATION.json содержит размеры, диапазон и распределение альфы, прозрачные углы, границы значимого рисунка, SHA-256 и результат визуальной проверки. V24_ContactSheet.png показывает текстуры на светлом/тёмном фоне при128px и в размерах64/32/16px. Полупрозрачные края проверены вместе с силуэтом; одних размеров для этого недостаточно.

## Подключение

Dev1: загрузить восемь PNG как Images, передать соответствие имени файла и Image ID. Не загружать превью-лист как текстуру. Dev2: подключить ID к существующим ключам Images.fx из таблицы выше. Обратите внимание: имена файлов confetti_1/2 имеют подчёркивание, ключи confetti1/2 — без него.

Существующий src/client/ArtIcon.luau уже содержит ArtIcon.burst для текстур из Images.fx. Белые текстуры поставлены как нейтральные маски: в текущем burst без отдельного Color они будут белыми, цвет при необходимости задаёт код эффекта. Монета и сердце имеют собственный цвет. Эта пачка не меняет настройки эмиттеров или игровую логику.

В Studio после загрузки и модерации проверить релиз/хит, оценку10/Rebirth, повышение и настроение сотрудника, звук и поломку. Смотреть на светлых и тёмных поверхностях, при движении и на телефоне; проверить размер, прозрачность и исчезновение, отсутствие квадратных ореолов. Проверить существующий режим «Меньше эффектов». Здесь выполнена проверка файлов и статических композиций, runtime-тест/загрузка в Roblox не выполнялись.
