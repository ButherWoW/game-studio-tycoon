# V38-3: проверка

- GameGallery: 69 деталей, 2346 пар; PanoramaCorner: 56 деталей, 1540 пар. Для каждой пары найден явный разделяющий support-plane сертификат с допуском численной точности. Объёмных пересечений не обнаружено, касание опорных поверхностей разрешено.
- Pivot — центр основания, локальный Y=0. +Z вперёд, всё Anchored. Только Model/Part/PointLight; по одному PointLight, Shadows=false. Нет скриптов, Decal/Texture/MeshPart или внешних asset IDs.
- RBXMX → RBXM → RBXMX через Rojo: нормализованные свойства, части и связи совпали.
- У обоих моделей менее 100 деталей; габариты в таблице README. При предложенных трансформациях лифт X −23…−17 / Z21…27, подход и передняя зона покупок свободны. Нет пересечений с перечисленными рабочими местами/резервами и их подходами по 3 studs (7/11 столов).
- Каждая новая часть проверена против текущей оболочки Floor/Skyscraper (снимки source/*_baseline.rbxmx). Конфликтов нет. Проверка B перенесена с исходной зоны стекла на центральную глухую стену. Пол C учтён подъёмом .025 при размещении.
- Осмотрены фронтальные и трёхчетвертные превью геометрии. Исходные ошибки пересечения рамки/акустической вставки, книг/полок и листьев/стебля исправлены до сдачи.

Не проверены: Studio/runtime, живые кнопки покупок, движения персонажей, изменения оформления/платных оболочек, реальная освещённость, камера и FPS. Проверка проходов не равна навигационному тесту всей карты. Если Dev 2 меняет трансформации или состав оболочек, повторить layout-проверку. Не заявляется, что модели уже появились в опубликованном плейсе.
