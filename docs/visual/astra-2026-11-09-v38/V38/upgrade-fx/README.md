# V38-2 — арт улучшения здания

Пять оригинальных RGBA PNG 256×256, прозрачный фон, без текста и цифр. Исходники получены built-in image_gen с transparent_background=true и уменьшены с сохранением alpha; дополнительных фонов или нарисованной шахматки нет.

| Файл | Применение Dev 2 |
|---|---|
| upg_dust.png | короткий выброс пыли у основания здания в начале/во время стройки; уменьшить непрозрачность через Transparency |
| upg_sparkle.png | несколько искр после завершения улучшения, возле нового этажа |
| upg_confetti.png | финальный праздничный выброс; в одном спрайте три бумажных кусочка: синий, золотой, фиолетовый |
| upg_ray.png | вертикальное сияние над крышей; плавно проявить и погасить, без постоянного источника света |
| upg_ring.png | тонкое расширяющееся кольцо у входа; плоскость и ориентацию выбирает игровой код |

Текстуры сами по себе не анимация: Dev 2 подключает ParticleEmitter/ленту и движение, Dev 1 загружает изображения. Атлас не используется — каждый файл является целым спрайтом, confetti показывает три цвета одновременно. Не разрезать на flipbook-кадры. Не подключать source/*.png: там оригиналы для воспроизведения.

FX_preview.png — каждый спрайт на тёмном и светлом фоне для проверки alpha. Никакой код игры, IDs, частоты эмиссии или платёжной логики не изменены. Опциональные upg_badge не входят в обязательные пять и не создавались.

Промпты и источники: PROMPTS.md, source_manifest.json, source/. Повторить преобразование: Pillow и `python3 prepare_fx.py`.

## Проверка в Studio
Загрузить пять PNG, проверить отсутствие прямоугольного фона/тёмной каймы, читаемость на дневном и вечернем небе. Проиграть стройку и открытие этажа; пыль не перекрывает управление/лифт, кольцо не закрывает вход, луч исчезает после эффекта. Проверить одновременное улучшение соседних участков и телефон. Код эффекта и его продолжительность остаются Dev 2.
