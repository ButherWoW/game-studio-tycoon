# Проверка V38-2

5/5 PNG 256×256 RGBA. У всех есть полностью прозрачные и полупрозрачные пиксели; край alpha не выше 1/255, содержимое не обрезано. Размер, режим, alpha-гистограмма и SHA256 записаны в VALIDATION.json. Превью на двух фонах осмотрено: искра, мягкая пыль, три цвета конфетти, вертикальный луч, тонкое полое кольцо соответствуют брифу. Текст/цифры/водяные знаки отсутствуют по визуальному осмотру.

Это исходный арт, не готовый скрипт анимации. Studio недоступен: ParticleEmitter, Blend/LightEmission, фильтрация alpha, масштаб и время жизни проверяет Dev 1/Dev 2 после загрузки. Не заявляется работа эффекта в опубликованном плейсе.
