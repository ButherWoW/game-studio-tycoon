## Происхождение и проверка

Создано встроенным OpenAI ImageGen: отдельный запрос на каждый логотип, transparent_background=true. Точные промпты и пути к исходникам в PROMPTS.json. Финальные файлы уменьшены до256×256 с сохранением исходной альфы; фон не вырезался по цвету.

VALIDATION.json содержит размеры, альфу, прозрачные углы, границы рисунка и SHA-256. V25_ContactSheet.png показывает полный размер на светлом фоне и128/64/40px на тёмном. Проверяются целые силуэты, читаемость, отсутствие надписей, брендов и агрессии.

## Подключение и тест

Dev1: загрузить PNG изV25/ как Images, передать соответствие filename → Image ID. Dev2: назначить ID существующим ключам Images.critics, перечисленным в таблице. Список полностью соответствует актуальному Config/Critics.

Проверить в окне оценок все четыре издания и диапазоны оценок, локализованные названия отдельно от изображения, контраст на фоне окна и маленький размер на телефоне. Не добавлять название прямо в картинку. Проверить результат после модерации Roblox.

Игровой код, цены и ID в этой пачке не меняются. Загрузка в Roblox и runtime-тест здесь не выполнялись.
