Робосова: синий корпус, большие серебристые оправы, бирюзовые глаза/вставки, золотые клюв и лапы, заострённые уши и многослойные перья-пластины.
Слайм: мятный округлый корпус с завитком и пузырьком, золотая пятиконечная звезда, розовые щёки, бирюзовый гранёный самоцвет на животе. Щёки касаются корпуса по опорной плоскости, не висят перед ним.

ICON_COMPARISON.png — принятые иконки рядом с тремя ракурсами новых моделей. Это нативная low-poly интерпретация: упрощены броня/поза совы и плавность завитка слайма, лица и значки выступают отдельными слоями. Точное совпадение рисунку не заявляется; художественное принятие за командой.

Звезда, клюв, перья и самоцвет построены из собственных нативных WedgePart: треугольники разбиты на прямоугольные призмы с общими гранями. Внешние Mesh ID и текстуры не нужны. Всего Model/Part/WedgePart, без скриптов и света.
