Кит: тёмно-синий округлый корпус, фиолетовые плавники/раздвоенный хвост, бирюзовое брюшко, золотая звезда и пиксельные отметки, розовые щёки и выразительное лицо.
Дракон: зелёный корпус/гребень, золотые рожки, синие крылья с бирюзовыми вставками, светлая мордочка, живот и коготки.
Трофей: золотая сужающаяся чаша с ободом/двумя ручками, синие основание и ботинки, лицо, кулачки и золотая звезда.

ICON_COMPARISON.png: принятые иконки рядом с тремя ракурсами. Нативная low-poly интерпретация, не точная реконструкция рисунка: выступающие плоские лицевые элементы и брюшки, гранёные крылья/плавники, упрощённая поза, слоистая чаша и сегментированные ручки. Небольшие технологические зазоры между некоторыми деталями видимы вблизи. Художественное принятие за командой.

Dev1: заменить три одноимённых шаблона ServerStorage.Mascots, импортировать только один формат RBXM или RBXMX, убрать старые копии. Body сохранён как PrimaryPart, прежние имена, pivot центра основания0, +Z, все Anchored. У трофея Body — реальный средний слой чаши, не отдельный невидимый объект. Не сбрасывать PivotOffset. Канонические batch-3 модели обновлены; код не менялся.

Высоты приведены к ≈3–3.25 studs. Кит широкий: 4.455 studs с плавниками, поэтому в Studio особенно проверить проходы/следование, камеры, лифт, дистанции до игрока и других маскотов. Для всех: отсутствие fallback, анимация по Body, высота над землёй, повороты/прыжки и FPS телефона при нескольких питомцах. Габариты изменились относительно старых; runtime не проверен. Внутренняя анимация частей не добавлялась.

9346 пар реальных нативных выпуклых форм без пересечений с допуском 1e-6 stud. До100 деталей каждый, имена/Body/pivot/Anchored и три бинарных roundtrip PASS. Только Model/Part/WedgePart, нет скриптов, света и внешних mesh/texture. Сертификаты и независимый XML-валидатор приложены.

Валидатор дополнен явной нормалью наклонной грани WedgePart: соседние призмы иногда имеют совпадающие центры bounding-box. Каждая разделяющая плоскость всё равно проверяется аналитической support-функцией; допуск не ослаблен. source/wedge_self_test.py проверяет касающиеся, раздельные и намеренно пересекающиеся клинья — PASS.

Сделано процедурно в Python из нативной геометрии; превью рендерят ту же геометрию. Иконки — ранее принятые собственные изображения проекта, не менялись. source/build.py/validate.py требуют NumPy/Pillow/Rojo; путь к Rojo адаптировать.
