## Использование

Владелец добавляет локализованный текст в пост отдельно от изображения. В картинках нет дат, таймеров, кодов сейфа, имён реальных игроков, цен или обещаний наград. День плана — сценарий анонса, не календарная дата. Дату запуска и публикацию надо согласовать с фактическим расписанием игры в UTC; дата ContentDrops.launchDate сейчас плейсхолдер.

Карточка голосования показывает только два доступных с запуска стиля — Classic и Cozy. Будущие волны Neon/Minimal/Сакура/Аврора не рекламируются как уже открытые. Карточки студий и победителей — иллюстрации, не реальные пользовательские скриншоты и не объявление фактических победителей. Перед конкурсным постом владелец может заменить их реальными результатами.

Сезонный баннер не дублировался: использовать готовый season_banner_generic.png из PR207 по ключу Images.social.seasonBannerGeneric. Картинки сейфа уже находятся в V27; реальные коды или подсказки в репозиторий не добавляются.

## Источники и проверка

Сделано встроенным OpenAI ImageGen, отдельным запросом на каждую карточку. Использованы собственные V13 сотрудники, V16 маскоты, Office/Garage, Classic/Cozy и V28 Зал славы/кубок. Точные промпты, пути к генерациям, референсы и цепочки правок в PROMPTS.json.

Финальные файлы пропорционально нормализованы до1920×1080 без растягивания. VALIDATION.json содержит размеры, непрозрачность и SHA-256. ContactSheet.png показывает все карточки уменьшенными; композиция, отсутствие текста и соответствие стартовому контенту проверяются визуально. Это рекламные иллюстрации по игровым моделям, не Studio-скриншоты.
