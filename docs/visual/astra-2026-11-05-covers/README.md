# V20 — 10 обложек игр

Финальные изображения: `V20/cover_<genreId>.png`, PNG 256×320. Полный набор: action, adventure, casual, rpg, simulation, puzzle, racing, strategy, sports, horror. Центр непрозрачный; все изображения полностью непрозрачные. Тёмная нижняя плашка нарисована поверх сцены и оставлена без надписей; целевая область названия — последние 60 px. Сверху золотая звёздочка студии.

Оригинальные сцены выполнены встроенным OpenAI ImageGen отдельным запросом на каждый жанр. Точные промпты и пути к исходным генерациям сохранены в PROMPTS.json. Финальные PNG уменьшены до целевого размера. Никаких названий игр, брендов, реальных консолей и логотипов. Экшен использует игрушечный бластер, RPG — деревянный меч-палку; хоррор — дружелюбные привидения и тыквы.

## Подключение

Dev1: загрузить десять PNG как Images, сохранить соответствие genreId → Image ID и передать Dev2. Проверить результат после модерации.

Dev2: подключить к жанрам Config/Genres / Config/Images согласно актуальной схеме. В окне релиза, на полке хитов, выставке и во франшизах сохранять пропорцию 4:5, избегать обрезки звезды и плашки. Название рисует код игры поверх нижней плашки; само изображение текста не содержит. При длинном названии использовать предусмотренный UI перенос/ограничение размера текста.

## Проверка

VALIDATION.json содержит размеры, непрозрачность и SHA-256 каждого файла. V20_ContactSheet.png показывает обложки при 256×320 и 64×80. Плашка, звезда, отсутствие текста, понятность жанров и дружелюбность horror проверяются визуально. Здесь не выполнялась загрузка в Roblox или runtime-проверка; Dev1 проверяет реальные окна и поверхность картриджа в Studio на телефоне.
