# NPC: посадка, шаг и тело владельца

Дополнение к PR #311: база `fix/npc-sitter-relax`. Не заменяет исправление Claude.

Поддержаны AnimationConstraint и Motor6D; поза применяется в PreSimulation после Animator. Сидение приоритетнее тега Walking, повторный сбор суставов учитывает streaming. При ходьбе сгибаются колени и компенсируется наклон стопы. Тело берётся из формы аватара владельца, одежда сотрудников сохраняется; при ошибке загрузки используется DefaultR15.

## Как проверить в Studio
Сначала применить #311 и этот PR. Запустить сервер с двумя клиентами: нанять сотрудника, дождаться посадки, проверить бёдра/колени и руки у клавиатуры. Проверить прогулку и возвращение к столу, остановку между шагами, повторный streaming. Проверить обычный и высокий/низкий аватар владельца. При необходимости отрегулировать высоту посадки после визуальной проверки. Диагностика в qa выполняется вручную на клиенте, в игру автоматически не включена.

Это не система IK с закреплёнными стопами. Проверки в Studio и сравнение с реальным аватаром ещё требуются.
