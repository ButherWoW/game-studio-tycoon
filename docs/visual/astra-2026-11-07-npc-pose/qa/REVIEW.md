# Independent NPC patch review

Reviewed against the current StaffService snapshot and PR #311's NpcWalkAnimator.
No Roblox Studio session was available. This is source review and syntax validation, not proof of runtime seating or walking.

## Corrections made during review

- Added needsCollect: all 11 expected R15 joints must still belong to the NPC. A cached, streamed-out joint can be non-nil while its Parent is nil; the old truthiness checks never replaced it.
- Sitting recollection replaces the entire joint snapshot while preserving posed, instead of merging only present fields and retaining stale references.
- setAngle ignores an unparented joint.
- Walker distance culling happens before recollection.
- Retained PR #311's metadata guard in relax, extended to AnimationConstraint. The existing boolean fix is a prerequisite; this patch should stack on #311.
- Updated the stale comment describing the reset guard.

The joint resolver accepts AnimationConstraint by joint name, <name>AnimationConstraint, or Attachment0's <name>RigAttachment, then falls back to Motor6D. Verify actual live rig names with the diagnostic if no joint is found.

## Body review

Only the owner's body part asset IDs and six proportions are copied. Employee face/clothing/colors/accessories are still generated by StaffAppearance/SkinService. BodySource identifies OwnerAvatar versus default fallback. Applied description is captured once per rebuild and destroyed after the NPC loop.

Limitations:
- Extreme owner avatar proportions can require a different seated root offset or chair position. Do not change the hard-coded offset blindly without a side view.
- If avatar-description retrieval fails, the code explicitly warns and uses default R15; it cannot guarantee rounded owner body in that failure case.
- The body's default animations/physical rig configuration must be verified with the current Roblox avatar-joint mode.

## Studio validation

Run diagnose_npcs.client.luau once on the CLIENT while viewing NPCs within 120 studs. It samples for 10 seconds and reads only. Do not publish it in StarterPlayerScripts. Remove it before measuring FPS.

1. Hire a new NPC, both with a real chair and without one. Check Sitting=true, NpcSitter tag, root anchored, body limbs unanchored; +/-90 degree hip/knee transforms should be observed.
2. Refresh NPCs repeatedly using the existing StudioDebug action. No boolean/Transform errors should appear.
3. Trigger a real break/StaffLife walk and rerun. Verify both knees flex and both foot Y positions vary relative to the root. WALK NOT OBSERVED is not a pass.
4. Return from break, remove/add tags and change style/body. Walking must not overwrite the seated pose.
5. Test both Motor6D and AnimationConstraint R15 rigs.
6. Stream NPCs out and back, including joints arriving after the model. Joints must be recollected.
7. Look at a side view on all floors: chair height, thighs above the seat, knees below the desk and feet near the floor.
8. Compare NPC HumanoidDescription body IDs/scales with the owner; employee clothes/face/hair must remain their own.

Current walking is a procedural swing with added forward-phase knee bend and ankle compensation. It is not ground-contact IK: the stance foot is not guaranteed planted, and obstacles/slopes are not solved. Claim visible foot lifting only after the live diagnostic, and natural gait only after visual acceptance.
