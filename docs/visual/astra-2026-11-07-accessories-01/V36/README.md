# V36 — аксессуары сотрудников, пачка 1

| Файл в models | Назначение | Детали с Handle |
|---|---|---:|
| skin_hoodie_coder_acc | синие наушники с сегментированной дугой, амбушюрами и кнопками | 26 |
| skin_sound_nerd_acc | студийные наушники, золотистая дуга и решётки | 36 |
| skin_writer_acc | открытые очки в толстой оправе с дужками и металлическими вставками | 18 |
| skin_intern_acc | рюкзак с карманами, молнией, пряжками, ручкой и значком без текста | 20 |

Каждый файл дан в RBXM и RBXMX — импортировать только один формат. Это замены аксессуарной папки соответствующих существующих скинов, не новая одежда. Рубашки/штаны и ID скинов не меняются. В каждом файле один Accessory; эти четыре варианта заменяют набор аксессуаров целиком. Старые дополнительные предметы не включены.

Dev1: после одобрения заменить содержимое соответствующих ServerStorage.Skins.Skin_<id> импортированной моделью (переименовать корневой Model в Skin_<id>). Удалить прежний набор этого скина, чтобы не получить двойные очки/наушники. Accessory остаётся прямым ребёнком Model. Проверить Humanoid:AddAccessory на настоящем R15: вид спереди/сбоку, ходьба, сидение и пересечение со всеми причёсками. Не менять ориентацию отдельных деталей.

Handle + стандартный Attachment: HatAttachment у трёх головных аксессуаров, BodyBackAttachment у рюкзака. Все детали незакреплённые, Massless, без коллизии/касания/запросов, соединены WeldConstraint с Handle. Поэтому правило Anchored для статического декора здесь не применяется.

+Z в исходной системе — спина персонажа, лицо Roblox смотрит на −Z. Pivot у аксессуара задаётся Handle/Attachment, правило Y0 для зданий не применяется. Внешних mesh/texture, скриптов и источников света нет. Нативные детали и материалы, загрузка Mesh ID не нужна.

previews: три ракурса каждого аксессуара и общий лист. Серая голова/торс — только ориентир офлайн-превью, в импортируемых файлах их нет. Это не полноценный R15 и не проверка посадки Studio. Сегменты дуги имеют узкие технологические зазоры, жёсткость обеспечивает сварка с Handle.

Проверки и воспроизведение: source/build.py, source/validate.py; нужны Pillow, NumPy и Rojo (путь к Rojo в скриптах адаптировать). 1202 пары видимых деталей, пересечений нет с допуском 1e-6 stud; 4 бинарных roundtrip PASS. Невидимый Handle исключён только из геометрического сравнения, включён в бюджет и проверку сварок.

Это первая аксессуарная пачка V36. Другие скины, дополнительные варианты шапок/значков, ломбард и концепты этажей остаются в очереди.
