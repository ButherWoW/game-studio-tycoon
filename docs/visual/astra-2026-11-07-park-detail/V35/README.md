Импортировать только одну версию каждого файла из models/: RBXM и RBXMX — одинаковые модели. recipes содержит копии для воспроизведения, повторно их не импортировать.

Клумба: девять растений четырёх видов, каменный бордюр, земля, листья и камешки. Габарит старой 3.8 × 1.22 × 3.8 соблюдён в пределах ±20%. Голубь: округлый сизый корпус, зелёно-фиолетовая шея, слои перьев и две тёмные полосы на крыльях, шагающая поза. PigeonFlock необязателен и не входит в эту пачку.

Все детали Anchored; основание и pivot Y=0, центр основания XZ=0, лицевая сторона +Z. Скриптов, источников света и внешних mesh/texture нет. Три ракурса каждой модели — в previews; это офлайн-превью нативной геометрии, не снимки Studio.
