RBXM/RBXMX — один и тот же набор, импортировать один формат. Dev1 после одобрения заменяет соответствующие ServerStorage.Skins.Skin_<id>: корневой Model переименовать в Skin_<id>, Accessory оставить прямым ребёнком. Удалить прежний набор, чтобы не наслаивать аксессуары.

Это новые наборы целиком: старые дополнительные предметы (ранец/палочка) не включены. Одежда и ID скинов не меняются. Один Accessory на скин, стандартные Handle + HatAttachment. Лицо −Z, спина +Z; правило Y0 для статического декора не применяется.

Все детали незакреплённые, Massless, CanCollide/CanTouch/CanQuery=false, WeldConstraint к Handle. Нативные Part/WedgePart; внешних mesh/texture, скриптов и источников света нет. Свечение — материал Neon, не отдельный свет. Прозрачный купол и визор — нативные детали Glass.

previews содержит три ракурса каждой модели и общий лист; серая голова — только ориентир, в файлы не экспортирована. Это офлайн-превью, не полноценная проверка R15. Высокая шляпа может конфликтовать с высокими причёсками: окончательное сочетание проверить в игре.

632 пары видимых деталей без пересечений с допуском 1e-6 stud. Прозрачные видимые детали включены, исключён только невидимый Handle. Бюджет включает Handle. Структура и четыре бинарных roundtrip PASS. Источники: source/build.py и validate.py, Pillow/NumPy/Rojo; путь к Rojo адаптировать.
