# Validation

PASS для концептуальных конвертов: четыре зоны внутри X/Z ±29; нет пересечений с перечисленными существующими объектами и резервами (за исключением заменяемых A=Lounge и D=ArtWall). Квадрат лифта и полоса Z22…29 не заняты новыми идеями.
Координаты взяты из актуального Upgrades.luau; AABB мебели вычислены по реальной геометрии XML, не по картинкам. Учтён поворот ServerRoom −90°. Габариты player desk/coffee/hits — резерв предыдущей проверки принятых этажей.
Просмотрены общий лист из четырёх эскизов и план 3-го этажа. Эскизы без текста, цифр и логотипов; планы содержат служебные подписи, это документация, не ассеты игры.
Ограничения: нет новых 3D-моделей, внутренние пересечения эскизной мебели математически не проверены. Декор оболочек/текущие кнопки в Studio не перечислены исчерпывающе. AABB SoundStudio пересекает показанный резерв подхода к лифту: существующий проход требует проверки реальной геометрии, новый декор не вводится туда.
Studio, аватарные проходы, телефон/FPS не проверены. Иллюстративные окна/лампы/растения не являются спецификацией дополнительных оболочек или света.
